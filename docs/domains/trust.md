상업적 중립성 고지, 표현 검수 규칙, 사진 데이터 처리 안내 — 기능명세서 7장.

## Current Status

**미구현.** `package-info.java`만 존재.

## Planned Features

- **7.1 상업적 중립성 고지**: 제품 판매·제휴를 하지 않는다는 사실을 첫 화면·화장대 상단에 고정 노출. 제품 구매 링크·가격·특정 병원 연결을 두지 않는다. 보유하지 않은 제품을 언급할 때도 브랜드명·제품명 없이 범주와 성분 단위까지만 말한다.
- **7.2 표현 검수 규칙**: 의료행위로 오인될 수 있는 용어(치료, 재활, 발병위험도, 사망위험도, 진단 결과, 정상·비정상 등)를 금지하고 대체 표현으로 규정. 모든 결과 화면에 "진단이 아닙니다" 고지 포함. 금지 용어와 대체 표현 쌍을 목록으로 관리(운영자가 관리).
- **7.3 사진 데이터 처리 안내**: 얼굴 사진의 저장 위치·처리 방침·삭제 방법을 촬영 화면과 설정 화면에서 안내. 개별/전체 사진 삭제 지원.

## Confirmed Decisions

- **얼굴 사진 원본은 서버에 영구 저장하지 않는다.** 기기에만 보관하고, 서버에는 분석 처리 중에만 임시로 존재하며 응답 반환 즉시 삭제한다(기능명세 7.3, [architecture.md](../architecture.md#얼굴-사진-처리-원칙)에도 이미 명시된 원칙).
- 기기를 변경하면 사진은 이관되지 않는다(명세 7.3에 명시).
- 사용자가 개별 사진을 삭제하면 3일차 판정 화면의 사진 대조 기능만 빠지고 나머지 흐름은 유지된다.
- 사진을 외부에 공유하거나 학습 데이터로 쓰지 않는다.
