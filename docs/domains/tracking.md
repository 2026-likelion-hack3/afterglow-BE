## Planned Features

- **6.1 수면·컨디션 1탭 기록**: 매일 수면/컨디션을 3지선다 한 번의 탭으로 기록(10초 이내, 글자 입력 없음). 날씨(온도·습도·자외선)는 자동 수집해 함께 저장. 스마트워치 연동은 선택 사항(없어도 전 기능 사용 가능).
